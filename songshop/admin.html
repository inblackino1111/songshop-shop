➕ เพิ่มหมวดหมู่แอพ / แบรนด์สินค้าใหม่

เพิ่มการ์ดแอพบนหน้าแรกและหน้าสินค้า พร้อมใส่รูปภาพจากลิงก์หรืออัปโหลดจากเครื่อง

📦 แก้ไขรายการสินค้า แพ็กเกจ ราคา สต็อก และรูปภาพ (Real-time)

ปรับแก้ชื่อแอพ รูปปกแอพ ราคา สต็อก รหัสสินค้าแม่ข่าย (baimonProductId) และแต้มที่ได้รับ แก้ปุ๊บหน้าบ้านเปลี่ยนปั๊บ

➕ เพิ่มบัญชีสมาชิกใหม่ / กำหนดพ้อยเริ่มต้น

สร้างยูสเซอร์ให้ลูกค้าหรือเพิ่มพ้อยให้สมาชิกได้ทันที

⭐ คำแนะนำระบบแก้ไขพ้อยเรียลไทม์

เมื่อแอดมินแก้พ้อยในตารางด้านล่าง แต้มบนแถบเมนูด้านขวาบนของลูกค้าจะเปลี่ยนทันทีโดยไม่ต้องรีเฟรช

  • กดปุ่ม +10 แต้ม หรือ +50 แต้ม เพื่อเพิ่มแต้มด่วน
  • หรือพิมพ์ตัวเลขพ้อยที่ต้องการในช่องตัวเลขแล้วกดปุ่ม บันทึกพ้อย
  • ลูกค้าสามารถนำแต้มไปแลกของรางวัลในหน้า "แลกของรางวัล" ได้ทันที

👥 รายชื่อสมาชิกทั้งหมด & แก้ไขพ้อยได้ทันที

แก้ไขพ้อยสะสมของสมาชิกแต่ละคนแบบ Real-time

ยูสเซอร์ (Username) รหัสผ่าน พ้อยสะสมปัจจุบัน แก้ไขพ้อย (กรอกตัวเลขใหม่) ปุ่มเพิ่ม/ลดพ้อยด่วน จัดการ

🎁 เพิ่มของรางวัลแลกแต้มชิ้นใหม่

กำหนดชื่อรางวัล แต้มที่ใช้แลก รูปภาพของรางวัล และรหัสโค้ดที่จะแจกเมื่อลูกค้ากดแลก

💡 ระบบตัดสต็อก FIFO (คนแลกปุ๊บลบปั๊บ):
• แบบที่ 1 (1 บรรทัดต่อ 1 ID): วางไอดีละ 1 บรรทัด เช่น เติม 5 บรรทัด = สต็อก 5 ID
• แบบที่ 2 (1 ID มีหลายบรรทัด): พิมพ์คั่นแต่ละ ID ด้วยเครื่องหมาย --- (เช่น มี Mail, Pass, PIN)
⚡ เมื่อลูกค้าคนแรกกดแลก ระบบจะหยิบ ID แรกไปส่งให้และลบ ID นั้นออกจากระบบทันที คนที่สองจะได้ ID ถัดไป

🏆 รายการของรางวัลแลกแต้มปัจจุบัน (แก้ไขแต้ม / รูป / โค้ดได้ทุกชิ้น)

ปรับแต้มที่ใช้แลกหรือเปลี่ยนรูปของรางวัลแล้วกดบันทึก หน้าบ้านจะอัปเดตทันที

🎨 แก้ไขชื่อเว็บไซต์ โลโก้ และข้อความหน้าแรก

เปลี่ยนชื่อเว็บ โลโก้ และข้อความแบนเนอร์หน้าแรกแบบ Real-time
